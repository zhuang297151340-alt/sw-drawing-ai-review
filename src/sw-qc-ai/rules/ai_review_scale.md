# AI 审核尺度（2026-10-23 v2）

> 直接写入 `sw_native_qc.py` 的 `AI_SYSTEM`，是 AI 判定的唯一口径。
> 原则：**帮设计者发现问题，不挑格式；宁可少报，不可乱报；同一张图结论要稳定。**

| # | 场景 | 规则 |
|---|---|---|
| 1 | 材料栏 | 只判断有没有写材料（**牌号即可**）。材料状态（6061-T5/T6）**写不写都可以**：写了不算错、没写也不要求补；不要要求写板厚、材料等级、标准号 |
| 2 | 倒角/圆角 | 不与板厚/壁厚/配合关联，不臆测在哪个面上 |
| 3 | 尺寸公差 0/未注 | 视为未注公差，按 GB/T 1804 允许，不报"无法识别/检验"；这类尺寸不单独发 AI |
| 4 | **板厚/轮廓** | 插件会把「已识别尺寸摘要」（板厚、长/宽/高）发给 AI；**摘要里有就不得再报"缺少板厚/轮廓"** |
| 5 | 表面处理 | 普通阳极氧化不要求膜厚等级、颜色验收、封闭处理 |
| 6 | 技术要求排版 | 不评论排版/编号/混编/语言表达 |
| 7 | 钣金件 | 不要求未注形位公差与粗糙度；有公差才判断加工可行性 |
| 8 | 稳定性 | temperature=0、top_p=1、输入键排序固定，同一张图应给出相同结论 |
| 9 | 重量/单重 | **不参与审核**：不要评论重量为 0 或缺失；单重字段不发给 AI |
| 10 | 表面处理(按材料) | 不锈钢(304/316)、铝(6061/5052)、铜、塑料：自带防腐/氧化膜，**未写表面处理属正常，不报**；碳钢/合金钢/铸铁：**未写应提示补**（镀锌/达克罗/发黑/喷漆/防锈油）；未知材料不判 |
| 11 | 钣金判定 | 类别可能写"外购件"；按 材料(板)/名称(弹片·支架·连接片…)/薄板尺寸 综合判断。钣金不要求 Ra，可提示在图框右上角标注「禁止表面加工」粗糙度符号 |

## 材料识别来源（2026-10-23 v3）\n- 直接读取 **SolidWorks 自带材质库**（`*.sldmat`，本机 669 个材料名）+ 牌号规则兜底（45/45#/Q235/304/6061/2A12…）\n- 材质库路径由插件通过 `ISldWorks.GetMaterialDatabases()` 写入 `.sw.json`\n\n## 轮廓尺寸识别（2026-10-23 v4）\n- 优先用**视图包围盒**（`IView.GetOutline` + 比例）算长宽，真实几何；\n- 无几何时才用尺寸推断，并过滤"展开/计算尺寸"（小数≥3 位），备注标明"可能含展开尺寸"。\n\n## 表面处理规则（2026-10-23 v5）\n- 惰性材料（不锈钢/铝/铜/塑料）：未注表面处理 → **通过**（记入通过项）\n- 易锈材料（碳钢/合金钢/铸铁/铸钢）：未注表面处理 → **报「一般」SURFACE-REQ**\n- 未知材料：不判（保持灵活）\n\n## 轮廓尺寸识别方式（2026-10-23 v7）
- **不用视图包围盒**：SW 的 GetOutline 会把图纸格式视图/标注/展开图算进去（实测整张图纸画面 148.5×105）
- 改为：按视图分组 → 断崖法剔除展开/计算尺寸 → 主视图（含最大有效尺寸）取长/宽
- 板厚 = 全图最小 ≤3mm 尺寸；高度无法自动区分时**列候选待人工确认**，不瞎猜
- 精确轮廓需要"尺寸↔几何关联"（未实现）

## 材料用途适宜性（2026-10-23 v8）
- 功能关键词 → 推荐材料：
  - 弹片/弹簧/簧片/膜片：301、302、17-7PH、631、65Mn、60Si2Mn、铍铜 QBe2
  - 齿轮：45、40Cr、42CrMo、20CrMnTi
  - 轴：45、40Cr、42CrMo
  - 耐磨件：GCr15、Cr12MoV、SKD11
- 例：弹片用 304 → 提示"弹性差、易塑性变形"，建议 301/302 冷轧等
- 只作提示，不下硬结论（设计可能出于成本/耐蚀有意选材）；AI 同步参与
## 齿轮材料放宽（2026-10-23 v9）
- 常规：45/40Cr/42CrMo/20CrMnTi（调质/渗碳淬火）
- **铝齿轮也常见**：6061/7075 + **硬质阳极氧化**（提高耐磨）→ 视为合理，不报
- 铝齿轮未注明硬质氧化 → 轻微提示"建议硬质阳极氧化"，不判错
- 其他材料做齿轮（如 304）→ "用途存疑"提示，建议确认载荷/耐磨要求
## 轴类材料放宽（2026-10-23 v10）
- 常规：45/40Cr/42CrMo（调质）
- 耐蚀/轻载/低速工况：**304、316、6061、7075 也很常见，不判错**
- 铝轴通常配硬质氧化；AI 可提示工况适用性，但不下硬结论

## 轮廓与提示清理（2026-10-23 v12）
- 钣金件轮廓 = **长 × 宽 + 板厚**（平板件没有"高"，不再列"候选尺寸"）
- 机加件才显示 长/宽/高
- 删除提示：「图面注明『未标注尺寸参考 3D 图』」（用户要求不再报）
## 属性读取口径（2026-10-23 v13）
- 插件同时读取零件 3D 的 **自定义(文档级)** 与 **配置特定** 属性
- 优先级：**自定义 > 配置特定**（自定义有值就用自定义；自定义没有才用配置特定）
- 图纸标题栏核对仍以"图上文字是否写了这些值"为准
- 读取来源会写入 `.sw.json` 的 `probe`：`零属[文档/自定义]`、`零属[配置/xxx]`、`配置补充: xxx`
## 公差单位与显示（2026-10-23 v14）
- SW `GetToleranceValues` 返回单位是**米**；判定按米换算（带毫米兜底），界面显示为毫米：如 `+0 / +0.01`、`±0.005`
- 修了一个 bug：算"就近 IT 等级"时变量名覆盖了尺寸对象，导致检查报 `'float' object has no attribute 'get'`
- 轮廓/板厚已使用的尺寸不再重复显示为「特征尺寸」
## 公差显示与加工能力（2026-10-23 v15）
- **对称公差**：SW 返回 [v,0] 或 [v,-v]，按 ±v 处理（宽度=2×|v|），显示 `±0.01`
- **加工能力反馈按零件/材料类别**（不再乱提工艺）：
  - 钣金件：可满足（激光/冲压/折弯）→ 可满足，需精冲或 CNC → **难保证**
  - 塑料件（ABS/POM 等）：注塑可满足 → 需 CNC 加工 → **难以保证**
  - 金属机加件：常规车铣 → 精车/精铣 → 需磨削 → 需研磨/珩磨 → 常规难满足
- 形位公差的能力反馈同样按类别给（钣金/塑料不提磨削研磨）

## 2026-10-23 v17 变更
1. **塑料件判定按尺寸分档**（工程经验值，待 GB/T 14486-2008 MT 数值表替换）：
   注塑常用可达公差 ≈ max(0.03, 0.02×³√尺寸) mm
   例：5mm≈0.034｜10mm≈0.043｜50mm≈0.074｜100mm≈0.093｜300mm≈0.134mm
   结论三档：`注塑可满足` / `注塑可满足（需较高模具精度）` / `注塑难保证（超出常用注塑公差）`
   **不再提 CNC/二次加工**（注塑件成型后一般不再加工）

## 塑料件工艺分流（2026-10-23 v18）
- **优先机加工的工程塑料**（PEEK / POM / PTFE / PA / 尼龙 / PPS / PI / PSU / PEI / PET）：
  按 **CNC** 判定：≥0.1mm「CNC 加工可满足」；0.05~0.1「（常规精度）」；0.02~0.05「（精加工）」；<0.02「CNC 也较难保证」
- **普通注塑塑料**（ABS / PP / PE / PC / PMMA / PVC …）：按尺寸分档的注塑可达公差判定
- 注塑超出能力时只说「注塑难保证（超出常用注塑公差）」，不提二次加工
## 可机加工塑料的精度口径（2026-10-23 v19）
不再硬性断言，改为**按材料给"常见可达公差带（参考值）"**，结论三档：

| 材料 | 常见可达（参考） |
|---|---|
| PEEK | 10~30 µm |
| POM / 尼龙 / PA / PPS / PSU / PC | 20~50 µm |
| PTFE | 50~100 µm |
| PMMA / 亚克力 | 10~20 µm（配合抛光可更高） |

- 公差带 ≥ 上限 → 「CNC 加工可满足」
- 介于区间 → 「CNC 可满足（需精加工，建议与加工厂确认）」
- 低于下限 → 「超出常见 CNC 水平（需与加工厂确认）」
- 文字里注明 **参考值**，最终以加工厂设备/工艺为准
- ABS / PP / PE / PVC 等外壳类仍按注塑判定
## 塑料件工艺分流按技术要求（2026-10-23 v20）
- 技术要求写「注塑/模塑/注射成型」→ 按**注塑**判定
- 技术要求写「CNC/数控/车削/铣削/加工中心/机加工」或引用 **GB/T 1804** → 按 **CNC** 判定
- 都没写：看类别（注塑件→注塑；机加件→CNC）；再按材料（可机加工塑料→CNC）
- ABS/PC/PMMA 等既可注塑也可机加：**以技术要求为准**
- 工程塑料**不出现研磨/珩磨/磨削**等金属工艺措辞
- 塑料 CNC 参考区间：ABS/PC 20~50µm、PMMA/亚克力 10~20µm、PEEK 10~30µm、POM 20~50µm、PTFE 50~100µm
