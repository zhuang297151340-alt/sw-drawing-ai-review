# 兼容性表

## 声明

目标兼容范围为 **64 位 SOLIDWORKS 2016–2024**。当前已完成的本机安装、注册和主要调试环境为 SOLIDWORKS 2016；其他版本尚未逐版本、逐 Service Pack 完成真实图纸全流程回归，因此不能宣称“全部版本已验证无问题”。

| SOLIDWORKS 版本 | 目标支持 | 当前验证状态 | 备注 |
|---|---:|---|---|
| 2016 64 位 | 是 | 已做主要开发与本机验证 | 推荐先用样图验证企业环境 |
| 2017–2020 64 位 | 是 | 待逐版本实机回归 | 依赖 COM/API 向后兼容性 |
| 2021–2024 64 位 | 是 | 待逐版本实机回归 | 需核对 .NET、API 与注册行为 |
| 32 位 SOLIDWORKS | 否 | 不支持 | 插件和安装包按 64 位构建 |
| SOLIDWORKS 2025+ | 未承诺 | 未验证 | 欢迎提交测试结果 |

## 操作系统

| 系统 | 状态 |
|---|---|
| Windows 10 64 位 | 目标支持 |
| Windows 11 64 位 | 目标支持 |
| Windows 7/8 | 不建议，未验证 |

## 版本验证建议

在新 SOLIDWORKS 版本发布或首次部署到某个 Service Pack 时，至少验证：

1. 插件注册、加载和卸载；
2. 工程图标题栏/属性读取；
3. 尺寸、公差、几何公差、粗糙度读取；
4. 人工归属与编辑后的数据一致性；
5. 通用 AI 连接、审核和报告；
6. PDF 导入、渲染、视觉审核和超时重试；
7. 升级安装是否保留 API 配置。

请在 Issue 中注明 SOLIDWORKS 完整版本号、Service Pack、Windows 版本和可脱敏复现步骤。
