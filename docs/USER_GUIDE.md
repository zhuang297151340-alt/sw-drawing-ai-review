# 操作手册

## 一、SOLIDWORKS 原生审图（主功能）

1. 在 SOLIDWORKS 中打开需要审核的工程图。
2. 打开 `工具 → 工程图QC → 审图`。
3. 点击“重新读图”，让插件重新读取当前工程图。
4. 在首页“尺寸/公差”中核对尺寸、公差、几何公差、粗糙度、备注和基准归属。
5. 对无法自动确定归属的几何公差使用“指定归属”；需要时设置自定义基准。
6. 点击“检查”。插件先执行本地规则，再执行已启用的通用 AI 语义检查。
7. 在“审核结果”中按严重、一般、轻微查看问题；单击问题查看结论、依据与修改建议。

### 统一数据原则

“尺寸/公差”列表是插件中审核窗口、报告和 AI 输入的统一数据来源。人工编辑、归属和基准设置应先反映到该表，再由其他功能读取，避免一个窗口显示已修正、另一个窗口仍用旧数据。

### 通用 AI 会收到什么

通用审核通道主要接收：

- 标题栏和图纸基本信息；
- 技术要求；
- 结构化的尺寸、公差、几何公差、粗糙度和备注；
- 本地规则检查已确认的事实和必要上下文。

默认不把整张工程图图片发送到通用通道。AI 应基于给定事实指出风险，不应虚构图中不存在的信息。

### 如何理解结果

- **严重**：可能直接影响装配、功能、制造或检验，建议优先复核。
- **一般**：存在规范性或工艺风险，通常需要设计者确认。
- **轻微**：可读性、完整性或优化建议，不应淹没真正的制造风险。
- **需确认**：证据不足时的提醒，不应阻止继续审核。

AI 结论属于辅助意见。尺寸作用、装配关系、功能基准和企业标准仍需由有经验的工程师结合产品上下文判断。

## 二、AI 设置

通用 AI 设置已内嵌在主审图窗口，位于“标准库”之后。填写提供商、API 地址、模型名和 API Key 后先测试连接，再保存。

升级安装时配置应被保留。不要把含 API Key 的配置文件、日志或截图提交到公开仓库和 Issues。

## 三、PDF 视觉整图审核（补充功能）

1. 打开 `工具 → 工程图QC → PDF视觉整图审核`。
2. 在“视觉模型设置”中配置支持图片输入的模型。
3. 导入 PDF，点击“检测”。
4. AI 直接给出审核结论；识别不确定项作为备注提示，不再用人工确认阻断审核。

PDF 通道依赖图像清晰度、字体、模型能力、网络和服务负载，可能出现漏识别、误识别、超时或限流。它适合快速筛查，不应替代原生工程图数据审查。

## 四、建议的工程使用方式

- 先审主功能识别出的结构化事实，再看 AI 风险判断。
- 对高风险问题回到原图验证，不只看文字报告。
- 企业自有标准应作为独立规则维护，并记录版本和适用产品。
- 同一张图纸修改后重新读图，避免沿用旧缓存。
- 发布或下发图纸前保留人工签字/审批环节。
